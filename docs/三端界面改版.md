# 三端界面与工作区改版

2026-11-07。统一采用浅灰底、白色卡片、紫色主操作、较大字号、清晰间距；保留三个独立入口和登录会话。

- 顾客商城：商品卡片、分类、搜索、精选／最新／价格排序、仅看有货；商品详情、购物车、结账、购买记录及查询订单继续使用独立购物流程。
- 商家后台：分组导航、手机横向导航、商品快捷查找；商品表格／卡片、分类和状态筛选、价格／名称／库存排序、分页、CSV导出、最多50件批量上架／下架；商品编辑改为侧边面板，保留成本、图片和手动语言内容。
- 生意总览：近7／30天销售趋势、可展开数据表、订单状态分布。按商家当地日历归类当前已付款订单的下单日期，不冒充实际每日到账；不显示虚构增长率、流量或评价。
- 顾客管理：从本店订单联系资料整理顾客、回购数量、已付款消费及订单明细。邮箱等联系资料不代表已验证会员身份。
- 平台后台：商家数量、正常／暂停／Pro方案数量，按商家名称、邮箱、网址标识搜索及状态筛选。保留人工订阅审核及所有业务明细的只读入口，不把不同币种销售额相加。

批量上下架使用现有权限和版本校验接口；发生并发修改时保留服务器上的库存，刷新并提示部分失败。取消或失败不清除选择。商品CSV标明交易币种，处理逗号、换行、引号和电子表格公式注入。
